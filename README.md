# 面包与矿石

Godot 4.6 制作的二维矿区经营游戏。

## 运行

用 Godot 导入 `project.godot`，按 F5 运行主场景，或在项目根目录执行：

```sh
godot --path .
```

游戏状态保存在内存中，重新启动会开始新矿区。

## 地图

地图没有固定矩形边界，向四个方向随工人探索按 32 × 32 格生成，支持负坐标。移动镜头只加载显示，不揭开迷雾。离开画面不会停止生产，返回也不会刷新已经挖掉的矿石；探索记录和地形修改在本局内保留。

生成器先用 Voronoi 伪片区决定铜、煤、花岗岩和空洞的区域倾向，再用跨片区的 Spot Noise 生成矿斑与洞室。部分铜、煤候选矿斑分别生成木材、铁矿，保留原矿斑形状与总密度；木材和铁矿都由普通工人一次性开采，不属于致密矿。大范围统计以砂岩占 75%～80%、其他矿物与空洞合计占 20%～25% 为目标，不逐区块强行凑配额。片区权重归一化，只改变成分，不把富矿区变成整片矿石。

斑点候选网格间距 16 格，影响半径 6～14 格，尺寸偏向小斑点并保留少量大斑点；长宽比和多频边缘扰动形成不同轮廓。中心间距按半径和的 0.6 倍加 0.5 格筛选，允许局部相接，强度取最大值而不累加，避免融合成大片。片区边缘混合参数，不裁切矿斑。致密铜矿、致密煤矿和水源独立稀疏放置，默认单格；水源保留相邻抽水机空间。相同种子与生成版本的地图不受探索顺序影响。

生成参数集中在 `scripts/map_generator.gd`：`REGION_SIZE` 控制地域尺度，`SPOT_GRID` / `SPOT_RATE` 控制候选密度，`MIN_RADIUS` / `MAX_RADIUS` 控制大小，`SPOT_SEPARATION` / `SPOT_GAP` 控制聚集程度，`PROFILES` 控制地域倾向，`SPECIALS` 分别配置特殊资源的出现概率与占地格数范围，`SPECIAL_GAP` 控制特殊资源最小间距。修改生成规则时递增 `VERSION`；不在玩家面板增加生成参数。

## 操作

- `G`：挖掘，按住左键框选矿石。
- `X`：取消，按住左键框选任务。
- 左下角建造栏：按农业与食品、工业与装备、水务、电力、物流、生活与环境、人口与金融分区，只显示图标，悬停查看名称。点击分区在上方展开建筑，再次点击收起；切换分区退出原来的建筑放置。选择建筑图标后，单击放置蓝图，拖动成排放置；传送带沿拖动方向铺设。
- 建造栏按“实物总量 − 未完成且未取消蓝图的材料需求”判断是否足够建造一座；缺任一种材料时图标变灰、不可选择或放置。蓝图放置后立即计入需求，但不扣实物、不绑定货源；连续拖放只放下材料足够的前段。蓝图仍可覆盖已探索的未挖矿石。工人挖清占地并实际送齐建材后才施工，完成时消耗一次；暂时无法到达的蓝图等待通路。取消立即释放数量承诺，只回收已到货或在途的实物，并撤销附带挖掘，独立下达的挖掘指令保留。
- 抽水机、净水器、打印仓、银行和普通传送带使用砂岩建造，数量分别为 8、8、12、12、1；打印仓生产工人的原料配方不变。
- 右键：取消建造预览，再次右键退出建造；非建造模式下切换取消工具。
- 点击工人、建筑或传送门：在右下角查看实时详情。随身物品、建筑库存和运输货物以图标加数量显示，悬停查看名称及自用、搬运信息；已穿戴装备和饮水、酒意等生效效果以独立 buff 图标显示，悬停查看效果及剩余时间或耐久。点击已探索的地形方格查看矿种、开采工时、产物及挖掘状态；挖空后更新为空地，水源单独显示。单击和拖动仍执行当前挖掘或取消工具；关闭按钮或 `Esc` 取消选择。
- 生产建筑详情中的加减按钮：调整产量；打印仓调整待制数量。
- 农田每批消耗 4 原水，浇水和收割各需 1 工时，中间独立生长 6 小时，收获 8 小麦；停止日产量不会丢弃已经浇水的这一批。
- 粗电线与普通电线可互连，也都能直接连接发电机和用电设备，承载上限分别为 3200W、800W。保留每段线路的容量限制，不新增过载损坏或电源优先级调度。燃煤电站最高 3200W，按实际输出耗煤；人力发电机最高 400W，不耗燃料，均需工人操作。变压站是可选的 800W 单向限流设备，需一人值班，左进右出，两侧均可接任一电线。
- 培育灯加速生长，喷泉每天消耗 10 原水并恢复附近工人的疲劳；点击显示三格范围，同类效果不叠加。电力传送带每件货物耗电 25W，快 20%，断电不丢货。
- 聚光灯与日光灯各耗电 200W，在横纵各三格内分别提高商品售价、建筑实际劳动工资 20%，同类不叠加，断电失效。售价影响矿枪、背包、清水及新增的衣物、麦酒、铁工具和肉，不影响面包、床费或运费；购物按到店时价格检查余额，工资仍从真实工厂款支付。两种灯都按建筑原点判定范围，点击显示范围。
- 食堂提供两个用餐座位，不生产或出售食品，不收费、不耗电。工人自带面包，综合路程、疲劳恢复与喷泉环境，选择十二格步行路程以内的可达空座或原地用餐，出发时预留座位。完整用餐恢复 10 疲劳，按实际用餐时间结算，不因食物数量增加，也不额外增加心情；离开后释放座位，原有喷泉效果保留。
- 标记致密矿后，由三格内接电的矿钻反复开采；普通工具不能挖掘。矿钻详情的移动图标可将其移到可达空地，仓储随之搬迁，电线需要重新连接。
- 每座建筑内置不限容量的仓库，只消耗已经送进本建筑的原料；运输途中显示物品，点击工人或建筑查看实物和数量。
- 工人通过同一套活动选择为蓝图和生产设施供料，新挖矿石可直接交给有需求的接收方，不必先回基地；没有可用需求时送到附近已建成建筑的仓储。选择时计入取货和交付路程，已有人负责运输的数量不会重复安排。
- 传送带末端可拖到建筑或非线状建筑蓝图的任一占地格。搬运任务先确定接收建筑，再选择直送或送到更近的相通传送带；货物沿线实际卸入接收建筑。断线或改接其他建筑时，在途货物等待原目的地重新接通，不会错送或重复计入库存。
- 左上角：暂停、倍速和报告图标。报告顶部切换“工人 / 物资”；工人页保留日期与工人筛选，物资页按图标名称、总数、最近五天库存曲线三列显示。曲线横轴按游戏天数等宽分格、标注天数，保留日内库存变化；点击任一列展开该物品的昨日产出、消耗，不提供历史日期选择。
- 总库存包含建筑、预留建材、运输途中及工人持有的实物，不包含未开采矿石。搬运、工资和交易不算产出或消耗；原料投入配方、完成建造、进食饮水及装备耗尽才计消耗。
- `WASD` 或鼠标中键拖动：移动视野；滚轮缩放；`Home` 回到基地。
- 空格：暂停或继续。

## 小人行为

### v3 基础产业与消费

本轮只实现 `v3.xlsx` 和《扩大系统设计》中选定的基础链条，未加入整洁度、住宅、寝具、繁殖、健康或科技树。表格只给输入输出关系，以下数量和效果是首版可调整参数。

| 建筑 | 每批输入 | 每批输出 | 劳动 |
| --- | --- | --- | --- |
| 磨房 | 4 小麦 | 8 面包 | 2h |
| 畜棚 | 2 小麦 + 2 原水 | 2 羊毛 | 喂养 1h、产毛 12h、剪毛 1h |
| 纺织坊 | 2 羊毛 | 2 布 | 2h |
| 裁缝铺 | 2 布 | 1 衣物 | 2h |
| 酿酒坊 | 2 小麦 + 2 原水 | 4 麦酒 | 2h |
| 熔炉 | 2 铁矿 + 1 煤矿 | 2 铁锭 | 2h |
| 锯木厂 | 1 木材 | 2 木板 | 1h |
| 铁匠铺 | 1 铁锭 + 1 木板 | 1 铁工具 | 2h |

所有新增生产建筑无需电力，沿用每日产量、实际送货和按进度付薪。面包进入磨房实物库存，可作为工资流入工人生活。新增建筑归入对应建造分区，仍只显示图标。

每座畜棚建成带 1 只羊。设定羊毛日产量后才安排喂养，产毛阶段无需值守且不受培育灯影响。详情中的屠宰图标发布 1h 劳动任务；已经喂养的批次会先完成剪毛，随后产出 6 肉并永久移除这只羊。重复点击不会重复产肉，没有自动补羊或繁殖。肉在畜棚出售，基础售价 1 面包，实际吃下一份恢复 20 饱食。

衣物、铁工具和原有装备购买后先成为个人持有物，再由工人自主穿戴或使用，不在付款时重复给予效果。衣物售价 4 面包，穿着期间心情 +15，72h 后耗尽；铁工具售价 5 面包，农田浇水、收割及加工生产效率 +30%，每完成一个适用劳动阶段消耗一次耐久，共 12 次，不加速自然生长、采矿、施工、发电、抽水或打印。

麦酒售价 2 面包，实际饮用后立即恢复 20 疲劳，并获得 4h 酒意：心情 +20、劳动效率 -20%。工人不会在已有酒意时连续饮用，也不会为酒或清水借款。清水仍保持原有饮用与减疲劳规则。新商品同样受聚光灯售价加成影响。

`scripts/simulation/worker_buffs.gd` 统一管理计时效果和心情、装备条件。计时效果同类不叠加，到期移除；衣物／酒意心情是临时修正，不写成永久经历。效率倍率相乘，仍在每段开工或续工时取样，不改变整批报酬；发电与变压的值班周期保持真实时间。持有、使用、到期和耗尽分别计入实物转移或消耗，人物详情显示实际物品与有效效果，不显示决策预算。

### 自主活动

工人自主比较带具体目标的工作、用餐、睡眠、购物和运输方案，不再按固定工作类别顺序派工，也不需要先挣够每日生活费才吃饭或休息。岗位距离、实际工资、疲劳、心情与当前购买力会影响选择；订单代表世界中的机会，并不强制指定某个人去做。

食物随实际进餐消耗，允许少量用餐和同日多餐。疲劳逐渐提高睡眠意愿，极度疲劳才强制退出其他活动；无钱或没有可用床时仍能免费地睡。借款只缓解当前紧急食物缺口，不为装备、床位或可选饮水融资。

银行放款后，工人持有一笔“贷款”特殊凭证，以图标和数量显示，不计入实物库存，也不能搬运、交易或消费。未还清期间，效果栏显示贷款 buff，悬停查看收入自动还款比例、还款顺序及借款和购物限制；还清后凭证与 buff 同时消失。凭证由现有借款记录生成，不另存或重复计算债务，不显示每日预算或待支付金额。

当前生计参数：新工人满饱食 180、疲劳 0、个人面包 0；每个面包恢复 10 饱食度，每天衰减 80，即维持饱食度需 8 面包。疲劳上限统一由 `scripts/game.gd` 的 `MAX_FATIGUE` 配置，当前为 120；劳动每小时增加 10 疲劳，地睡、床睡每小时分别恢复 15、25，床费每次 2 面包。工资仍为基准工时每小时 1 面包，收入需求和活动评分规则不另改，仅同步疲劳上限的相对尺度：满腹后仍会随饱食度下降提前赚钱备粮，吃饭不必先达到储备目标。大致每日一觉与闲暇是方向，不是固定作息或每天强制次数；远距离运输、消费与设施布局会改变节奏。当前饱食度降到零不会死亡，死亡机制尚未实现。

采矿、建造和生产按任务或批次完成结算；发电与变压值班每游戏小时结算一次。报酬在任务首次开工时锁定，心情与装备只影响这一段的速度、不改变完整任务报酬；效率和饮水减疲劳条件在每次开工或续班时取样。中断、取消、换人和资金用尽统一按真实进度结算未付份额，不四舍五入、不提前生成未完成产物；真实进度和已投入材料独立保留。工资到账时才还款，余额和食物允许小数。

出发前预留工作位置、床或座位，结束或取消时释放；工程进度、已投入材料与携带货物独立保留。连续值班在阶段边界重新选择，普通活动不因每一帧的分数变化来回切换。当前权重是首版平衡参数，尚非长期经济平衡结论。

架构依据、执行契约及当前初始规则见 [小人模拟架构](小人模拟架构设计.md)。

## 代码导航

物品效果与玩法规则写在对应实现旁的注释中，数值以代码配置为准。

心情系统的规则、模块边界、购物与工资约束、扩展方式见 [心情系统实现](mood.md)。

| 位置 | 内容 |
| --- | --- |
| `scripts/game.gd` | 世界与输入、模拟时钟、生产配方、仓储运输、劳动及交易结算 |
| `scripts/simulation/worker_state_tree.gd` | 活动选择入口、父活动校验、阶段生命周期、短暂饮水与退出清理 |
| `scripts/simulation/activity_selection.gd`、`worker_context.gd` | 具体候选、可行性、路径与效用评价；不产生交易或占用副作用 |
| `scripts/simulation/smart_objects.gd` | 交互机会、独占槽位、成组认领及带版本的预留凭据 |
| `scripts/simulation/activities/` | 劳动、生活、经济与交付四类流程及共用移动任务 |
| `scripts/worker_mood.gd` | 心情经历、运行环境影响、自然恢复、效率倍率、购物倾向与机械岗位回避规则 |
| `scripts/simulation/worker_buffs.gd` | 饮水、酒意等计时效果，心情与装备条件，效率、疲劳和携带倍率 |
| `scripts/map_generator.gd` | 确定性 Voronoi + Spot Noise 分块生成与特殊资源放置 |
| `scripts/world_navigation.gd` | 已生成通行格的稀疏四向寻路 |
| `scripts/portal.gd` | 传送门交付与收支记录 |
| `scripts/view/` | 世界显示、建筑与人物动画、HUD |
| `scripts/daily_report.gd` | 每日报告窗口 |
| `scenes/` | 世界分层与可复用实体场景 |
| `assets/world/`、`assets/icons/` | 美术源文件 |
| `tests/` | 行为测试与场景夹具 |

`main.tscn` 将世界与 HUD 分开。世界依次包含地面输入、地形背景、水源、矿块、建筑、人物、迷雾和交互标记；HUD 位于独立 CanvasLayer。实体使用 Viewport 原生拾取。
