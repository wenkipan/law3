# 面包与矿石

Godot 4.6 制作的二维矿区经营游戏。

## 运行

用 Godot 导入 `project.godot`，按 F5 运行主场景，或在项目根目录执行：

```sh
godot --path .
```

游戏状态保存在内存中，重新启动会开始新矿区。

## 地图

地图没有固定矩形边界，向四个方向随工人探索按 32 × 32 格生成，支持负坐标。移动镜头只加载显示，不揭开迷雾。离开画面不会停止生产，返回也不会刷新已经挖掉的矿石；探索记录和地形修改在本局内保留。

生成器先用 Voronoi 伪片区决定铜、煤、花岗岩和空洞的区域倾向，再用跨片区的 Spot Noise 生成矿斑与洞室。大范围统计以砂岩占 75%～80%、其他矿物与空洞合计占 20%～25% 为目标，不逐区块强行凑配额。片区权重归一化，只改变成分，不把富矿区变成整片矿石。

斑点候选网格间距 16 格，影响半径 6～14 格，尺寸偏向小斑点并保留少量大斑点；长宽比和多频边缘扰动形成不同轮廓。中心间距按半径和的 0.6 倍加 0.5 格筛选，允许局部相接，强度取最大值而不累加，避免融合成大片。片区边缘混合参数，不裁切矿斑。致密铜矿、致密煤矿和水源独立稀疏放置，默认单格；水源保留相邻抽水机空间。相同种子与生成版本的地图不受探索顺序影响。

生成参数集中在 `scripts/map_generator.gd`：`REGION_SIZE` 控制地域尺度，`SPOT_GRID` / `SPOT_RATE` 控制候选密度，`MIN_RADIUS` / `MAX_RADIUS` 控制大小，`SPOT_SEPARATION` / `SPOT_GAP` 控制聚集程度，`PROFILES` 控制地域倾向，`SPECIALS` 分别配置特殊资源的出现概率与占地格数范围，`SPECIAL_GAP` 控制特殊资源最小间距。修改生成规则时递增 `VERSION`；不在玩家面板增加生成参数。

## 操作

- `G`：挖掘，按住左键框选矿石。
- `X`：取消，按住左键框选任务。
- 左下角建造栏：选择建筑图标，单击放置蓝图，拖动成排放置；传送带沿拖动方向铺设。
- 蓝图可以覆盖已探索的未挖矿石：放置时锁定建材，工人先挖清占地再施工；暂时无法到达的蓝图会等待通路。取消蓝图会退回建材并撤销附带挖掘，独立下达的挖掘指令保留。
- 右键：取消建造预览，再次右键退出建造；非建造模式下切换取消工具。
- 点击工人、建筑或传送门：在右下角查看实时详情。点击已探索的地形方格查看矿种、开采工时、产物及挖掘状态；挖空后更新为空地，水源单独显示。单击和拖动仍执行当前挖掘或取消工具；关闭按钮或 `Esc` 取消选择。
- 生产建筑详情中的加减按钮：调整产量；打印仓调整待制数量。
- 农田每批消耗 4 原水，浇水和收割各需 1 工时，中间独立生长 6 小时，收获 8 小麦；停止日产量不会丢弃已经浇水的这一批。
- 电站经两格宽高压走廊连接变压站左侧，再从变压站右侧铺低压线到用电设备。同类线路相交接通；容量分别为 3200W、800W，电站按实际输出耗煤，电站和变压站都需要值班工人。
- 培育灯加速生长，喷泉每天消耗 10 原水并恢复附近工人的疲劳；点击显示三格范围，同类效果不叠加。电力传送带每件货物耗电 25W，快 20%，断电不丢货。
- 标记致密矿后，由三格内接电的矿钻反复开采；普通工具不能挖掘。矿钻详情的移动图标可将其移到可达空地，仓储随之搬迁，电线需要重新连接。
- 每座建筑内置不限容量的仓库，只消耗已经送进本建筑的原料；运输途中显示物品，点击工人或建筑查看实物和数量。
- 传送带末端可拖到已建成建筑的任一占地格。搬运任务先确定接收建筑，再选择直送或送到更近的相通传送带；货物沿线实际卸入接收建筑。断线或改接其他建筑时，在途货物等待原目的地重新接通，不会错送或重复计入库存。
- 左上角：暂停、倍速和报告图标。报告顶部切换“工人 / 物资”；工人页保留日期与工人筛选，物资页按图标名称、总数、最近五天库存曲线三列显示。曲线横轴按游戏天数等宽分格、标注天数，保留日内库存变化；点击任一列展开该物品的昨日产出、消耗，不提供历史日期选择。
- 总库存包含建筑、预留建材、运输途中及工人持有的实物，不包含未开采矿石。搬运、工资和交易不算产出或消耗；原料投入配方、完成建造、进食饮水及装备耗尽才计消耗。
- `WASD` 或鼠标中键拖动：移动视野；滚轮缩放；`Home` 回到基地。
- 空格：暂停或继续。

## 代码导航

物品效果与玩法规则写在对应实现旁的注释中，数值以代码配置为准。

心情系统的规则、模块边界、购物与工资约束、扩展方式见 [心情系统实现](mood.md)。

| 位置 | 内容 |
| --- | --- |
| `scripts/game.gd` | 物品与建筑配置、生产配方、工人决策、仓储运输、交易、模拟及输入 |
| `scripts/worker_mood.gd` | 心情经历、运行环境影响、自然恢复、效率倍率、购物倾向与机械岗位回避规则 |
| `scripts/map_generator.gd` | 确定性 Voronoi + Spot Noise 分块生成与特殊资源放置 |
| `scripts/world_navigation.gd` | 已生成通行格的稀疏四向寻路 |
| `scripts/portal.gd` | 传送门交付与收支记录 |
| `scripts/view/` | 世界显示、建筑与人物动画、HUD |
| `scripts/daily_report.gd` | 每日报告窗口 |
| `scenes/` | 世界分层与可复用实体场景 |
| `assets/world/`、`assets/icons/` | 美术源文件 |
| `tests/` | 行为测试与场景夹具 |

`main.tscn` 将世界与 HUD 分开。世界依次包含地面输入、地形背景、水源、矿块、建筑、人物、迷雾和交互标记；HUD 位于独立 CanvasLayer。实体使用 Viewport 原生拾取。

## 检查

```sh
godot --headless --log-file /tmp/law3-tests.log --path . --script tests/run.gd
```

交互与渲染检查使用原生窗口，会移动鼠标并保存截图：

```sh
godot --resolution 1440x900 --log-file /tmp/law3-native-tests.log --path . --script tests/run.gd -- --suite=interaction --native
```

用例约定与单组运行方法见 [测试标准](tests/README.md)，工程约定见 [AGENTS.md](AGENTS.md)。
